# DJ KOLJA ONE · Karaoke

Karaoke-Web-App im Branddesign: DJ-Konsole und Bühnenbild für die Mainstage, autarker Kiosk für den Nebenraum, Anmeldung per Handy (QR-Code).

Statische Website ohne Build-Schritt – `index.html` liegt im Wurzelverzeichnis.

**Cloudflare Pages:** Framework-Voreinstellung „None“, Build-Befehl leer, Ausgabeverzeichnis `/`.
